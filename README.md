# Kindle Studio & Native AI Chat

> Превратите ваш Amazon Kindle (Kindle Keyboard 3, 4, 5, Paperwhite) в E-Ink монитор, настольные часы, системный дашборд и автономный терминал ИИ-помощника с русской слепой печатью.

---

## Возможности проекта

### 1. Kindle Studio 2.0 (Десктопное приложение для ПК)
* **Аутентичный E-Ink дизайн:** Высококонтрастный стиль Carta E-Paper (#f5f4ef / #111111), четкие ретро-заголовки, увеличенные шрифты и элементы управления на всех 7 вкладках приложения.
* **Стриминг экрана:** Передает экран компьютера на дисплей Kindle в реальном времени (дополнительный E-Ink монитор для чтения кода, логов или документации без нагрузки на зрение).
* **Системный дашборд и погода:** Отображает загрузку процессора, оперативной памяти, накопителя, сетевой трафик, прогноз погоды и календарь.
* **Настольные часы:** Полноэкранный циферблат с текущей датой и погодой для прикроватной тумбочки или рабочего места.
* **Заметки и список задач:** Интерактивный To-Do список с возможностью вывода на экран в виде стикера с чекбоксами.
* **Холст и просмотр изображений:** Инструменты рисования, слайдшоу и качественный дизеринг по алгоритму Флойда-Стейнберга для четкой передачи полутонов на E-Ink.
* **Беспроводная загрузка и конвертер книг:** Отображает список книг на читалке (по Wi-Fi через SSH или по USB) с мгновенным поиском и удалением файлов. Поддерживает выбор любых форматов (.epub, .fb2, .docx, .txt, .pdf), автоматически конвертирует их через Calibre в формат читалки (.mobi, .azw3) и отправляет по воздуху с автообновлением библиотеки Kindle.
* **Полная двуязычная локализация (RU / EN):** Мгновенное переключение языка программы между русским и английским одной кнопкой в верхней панели — все надписи, подсказки и генерируемые экраны (часы, дашборд, задачи) адаптируются под выбранный язык.
* **Мастер установки:** Автоматическое обнаружение подключенного по USB Kindle и развертывание ИИ-чата и необходимых компонентов в один клик.

---

### 2. Kindle AI Chat (Автономный ИИ на устройстве)
* **Автономная работа на процессоре книги:** После установки подключение к компьютеру не требуется — читалка самостоятельно подключается к Wi-Fi и отправляет запросы через API Polza.ai (модель GLM-5.3 Flash).
* **Прямая отрисовка без эмуляторов терминала:** Бинарный файл на Go производит прямую запись во фреймбуфер читалки (`/dev/fb0`) и управляет обновлением контроллера E-Ink.
* **Высококонтрастный темный режим (Dark Mode):** Белый текст на сплошном черном фоне — максимальная четкость и читаемость дисплея Pearl E-Ink без размытия и серых артефактов.
* **Полноценная русская слепая печать (ЙЦУКЕН) на аппаратной клавиатуре:**
  * Переключение раскладки: кнопка `SYM` (`[RU]` / `[EN]`).
  * Дополнительные буквы русского алфавита через `Alt`:
    * `Alt + P` = х
    * `Alt + O` = ъ
    * `Alt + L` = ж
    * `Alt + K` = э
    * `Alt + M` = б
    * `Alt + E` = ё
  * Знаки препинания: двойное нажатие клавиши `Пробел` вставляет точку с пробелом (`. `), комбинация `Alt + Пробел` вставляет запятую с пробелом (`, `).
  * Прокрутка длинных сообщений боковыми клавишами перелистывания страниц или стрелками джойстика.
  * Мгновенный выход в библиотеку по нажатию кнопки `HOME` или `BACK`.

## Руководство: Джейлбрейк и подготовка Kindle

Инструкция ориентирована на модель Kindle Keyboard 3 (K3W / K3G), а также подходит для Kindle 4 и Kindle 5.

### Шаг 1. Джейлбрейк (Jailbreak)
1. Подключите Kindle к компьютеру кабелем USB.
2. Загрузите архив джейлбрейка из ветки MobileRead Kindle Jailbreak.
3. Скопируйте файл обновления, соответствующий вашей модели (например, `update_jailbreak_0.13.N_k3w_install.bin`), в корень накопителя Kindle.
4. Выполните безопасное извлечение диска в операционной системе и отключите кабель.
5. На устройстве перейдите: `[Home]` -> `[Menu]` -> `Settings` -> `[Menu]` -> `Update Your Kindle`.
6. Дождитесь перезагрузки устройства. В нижней части экрана появится сообщение об успешной установке (`Jailbreak succeeded`).

---

### Шаг 2. Установка MKK и KUAL (Лаунчер приложений)
1. Подключите Kindle по USB.
2. Скопируйте файл обновления MKK (например, `update_mkk_20141129_k3w_install.bin`) в корень накопителя и примените через меню `Settings` -> `Update Your Kindle`.
3. Скопируйте файл `KUAL-KDK-1.0.azw2` в директорию `documents/` на диске Kindle.
4. Отключите устройство. В домашней библиотеке появится документ `KUAL`, открывающий меню запуска сторонних программ.

---

### Шаг 3. Установка USBNetwork (Сетевой доступ по SSH и Wi-Fi)
1. Скопируйте установочный пакет `update_usbnetwork_..._k3w_install.bin` в корень накопителя и обновите устройство через `Update Your Kindle`.
2. В директории `usbnet/` на устройстве активируйте сетевой доступ для работы стриминга экрана из Kindle Studio.

## Установка AI Chat на Kindle

### Способ 1: Автоматически через Kindle Studio (Рекомендуется)
1. Подключите Kindle к ПК по USB.
2. Запустите файл `Kindle_GUI.bat` (или выполните `python kindle_studio.py`).
3. Откройте вкладку «Прошивка & AI».
4. Нажмите «Найти Kindle (USB)» для определения диска читалки.
5. Введите ключ от Polza.ai в соответствующее поле.
6. Нажмите «Установить AI Chat на Kindle». Приложение автоматически скопирует исполняемые файлы, скрипты и расширение KUAL, а также сформирует конфигурационный файл.
7. Извлеките накопитель, откройте KUAL на устройстве и выберите `AI Chat (GLM-5.3)`.

---

### Способ 2: Вручную
1. Скопируйте каталог `ai_deploy/ai` в корень диска Kindle (путь `/mnt/us/ai`).
2. Скопируйте каталог `ai_deploy/extensions/ai_chat` в `extensions/ai_chat` на диске Kindle.
3. Создайте файл `/mnt/us/ai/config.json` со структурой:
   ```json
   {
     "api_key": "ВАШ_КЛЮЧ_POLZA_AI",
     "model": "z-ai/glm-5.3-flash"
   }
   ```
4. Безопасно отключите устройство и запустите пункт `AI Chat (GLM-5.3)` через KUAL.

## Таблица клавиш управления в AI Chat

| Действие | Клавиша |
| :--- | :--- |
| Переключение языка (RU / EN) | Кнопка `SYM` (индикатор `[RU]` или `[EN]`) |
| Слепая печать ЙЦУКЕН | `Q..P` -> `й..з`, `A..L` -> `ф..д`, `Z..M` -> `я..ь`, `.` -> `ю` |
| Дополнительные буквы | `Alt + P` = х, `Alt + O` = ъ, `Alt + L` = ж, `Alt + K` = э, `Alt + M` = б, `Alt + E` = ё |
| Точка | Двойное нажатие клавиши `Пробел` (или `Alt + .`) |
| Запятая | `Alt + Пробел` (вставляет запятую и пробел) |
| Вопросительный знак (?) | `Shift + Alt + .` |
| Восклицательный знак (!) | `Alt + A` |
| Дефис (-) | `Alt + Z` |
| Прокрутка ответа | Боковые клавиши перелистывания страниц или джойстик Вверх / Вниз |
| Отправка запроса | Клавиша `Enter` |
| Сброс диалога | Команда `/new` в строке ввода |
| Выход в библиотеку | Физическая кнопка `HOME` или `BACK` |

## Запуск Kindle Studio на компьютере

### Запуск приложения:
Запустите `Kindle_GUI.bat` или выполните команду:
```bash
python kindle_studio.py
```

### Зависимости:
* Python 3.9+
* Установка необходимых библиотек:
  ```bash
  pip install pillow requests mss psutil
  ```

### Конфигурация (`config.json`):
Создайте файл `config.json` на основе шаблона `config.example.json`:
```json
{
  "ip": "192.168.1.100",
  "city": "Moscow",
  "rotation": 270,
  "api_key": "YOUR_KEY_HERE",
  "model": "z-ai/glm-5.3-flash"
}
```

## Структура файлов проекта

```text
├── kindle_studio.py           # Графический интерфейс управления Kindle Studio
├── Kindle_GUI.bat             # Скрипт быстрого запуска для Windows
├── kindle_chat_gui.go         # Исходный код нативного E-Ink чата на Go (прямые вызовы Linux API)
├── font_data.go               # Встроенный растровый русский и латинский шрифт 24px
├── gen_font.py                # Конвертер шрифтов из формата bdf/hex в Go
├── kindle-ai                  # Скомпилированный бинарный файл под архитектуру ARMv6 (Linux 2.6)
├── ai_deploy/                 # Готовый пакет для установки на читалку (каталоги ai и extensions)
│   ├── ai/                    # Исполняемый файл, запуск и фоновый обработчик curl
│   └── extensions/ai_chat/    # Конфигурация меню запуска для KUAL
├── kindle_books.py            # Модуль беспроводной синхронизации книг и конвертера Calibre
├── kindle_display.py          # Модуль конвертации и вывода графики на E-Ink
├── kindle_stream.py           # Захват и непрерывный стриминг экрана ПК
├── kindle_pic.py              # Обработка изображений и алгоритм дизеринга
├── config.example.json        # Пример конфигурационного файла
├── README.md                  # Документация проекта (на русском языке)
└── README_EN.md               # Документация проекта (на английском языке)
```
